# Запуск ML-моделей в промышленной среде

Материалы курса для студентов. Занятия проходят онлайн. В командном проекте вы создаёте ML-сервис, проверяете его и моделируете эксплуатацию.

**С чего начать:** прочитайте [требования к модулю 2](project-m2.md), заранее посмотрите [объём работ в модуле 3](project-m3.md), выберите [тему и датасет](topics.md) и выполните [задание Z01](assignments/Z01.md).

## Материалы курса

- [Лекции](lectures/README.md) — PDF презентаций `L01`–`L12`.
- [Семинары](seminars/README.md) — практические материалы `S01`–`S14`.
- [Задания](assignments/README.md) — отдельные условия `Z01`–`Z13`.
- [Проект, модуль 2](project-m2.md) — первая версия модели и сервиса, требования к первой защите.
- [Проект, модуль 3](project-m3.md) — эксплуатация, вторая версия, инциденты и итоговая защита.
- [Темы проектов](topics.md) — варианты на выбор; собственная тема допускается по согласованию.

Контрольные мероприятия обозначаются `EK1`–`EK4`. **Календарные даты занятий и точные сроки сдачи публикуются на учебной платформе**; в этом репозитории используются постоянные номера занятий и заданий.
